## 当前可用版本（2026-10-29）

Colendar 当前已经打通“创建任务包 → 日历排程 → 到点确认 → 分步骤计时 → 完成反馈 → 再次开始”的本地闭环。工程包名为 `com.example.colendar`，兼容 API 23，应用 HAP 与 ohosTest HAP 均可成功构建。

已经实现：

- 任务包创建、编辑、步骤时长与低风险关联动作。
- 月/周/日历、重复安排、单实例编辑、拖放预览、磁吸、聚焦、拉伸、复制和剪切。
- 横屏执行页、3-2-1 准备、累计进度、暂停/继续、步骤切换、完成次数与重启恢复。
- 应用内 1 分钟提示和开始前 20 秒确认。
- 版本化模板导入/导出、系统分享和 Share Kit 碰一碰发送。

仍受外部条件阻塞：系统代理提醒需要 AGC 开放能力与签名 Profile；碰一碰需要两台支持设备实测；创意工坊需要真实用户验证、账号、服务端、审核和隐私治理。下文中涉及社区、跨设备和高权限系统联动的内容属于长期愿景，不代表当前版本已交付。

## 产品理念

Colendar 不只是一款日程管理工具，而是一位帮助用户进入和保持任务节奏的数字陪伴者。

传统的日历软件管理的是**时间点**——提醒你几点开会、几点健身。Colendar 管理的则是**任务包**——你不仅知道几点要做什么，也知道它包含哪些步骤、每一步花多长时间，并在执行时得到连续引导。

我们的核心理念是：**时间不该被切割，而该被组装。**

## 功能详情

### 🧩 模块化任务包（Task Pack）

用户可以预设一个"任务包"，内含多个子步骤及其时长。任务包是 Colendar 中一切安排的最小单元。

```
📦 健身包
  ├── 🏃 有氧运动 — 20 分钟
  ├── 💧 休息 — 5 分钟
  └── 🏋️ 力量训练 — 20 分钟
```

每个子步骤支持：标题、时长、清单列表、关联动作（见下文自动化联动）。任务包创建完成后，即可像积木一样在后续日程中反复使用。

---

### ✋ 拖拽式日程编排

在日历视图中，将建好的任务包直接拖拽到目标日期与时间段，即可完成安排。无需繁琐的起止时间设置。

**智能时长适配**：当拖入的时间空档与任务包总时长不匹配时，系统提供多种处理方案：

| 策略 | 行为 |
|---|---|
| 📐 等比缩放 | 按比例调整所有子步骤的时长 |
| ⏭ 压缩缓冲 | 优先压缩休息 / 缓冲类步骤的时长 |
| ⚡ 跳过可选 | 跳过标记为"可选"的子步骤 |
| 🔔 提示调整 | 提示用户手动调整，或建议最近可用空档 |

---

### 🌐 创意工坊（社区生态）

用户可将创建的任务包模板上传至创意工坊，供他人浏览、评分、导入使用。

```yaml
# 示例模板：高效会议流程
name: "高效会议流程"
category: 工作 / 会议
steps:
  - title: 议程同步
    duration: 5m
  - title: 议题讨论
    duration: 25m
  - title: 结论确认与分工
    duration: 10m
checklist:
  - 确认参会人员
  - 准备好共享文档
  - 设置录屏
```

**社区功能**：点赞 / 收藏 / 下载排行 / 分类浏览 / 创作者关注。每个模板包含结构化的步骤说明、时长、清单，以及可选的关联动作配置。

> **长期愿景**：只有在本地闭环和真实分享需求得到验证后，Colendar 才会从工具扩展为有审核与治理能力的模板平台。

---

### 📱 一碰传分享

基于鸿蒙原生 NFC 能力，手机碰一下即可快速分享任务模板或完整日程。无需打开 App、无需搜索、无需扫码。

| 场景 | 体验 |
|---|---|
| 🏋️ 健身教练 | 在健身房贴 NFC 标签，学员碰一下即导入本周训练计划 |
| 🏠 智能家居 | 客厅 NFC 标签碰一下，获取"家庭 Wi-Fi 连接 + 舒适音乐"日程 |
| 🎓 课堂 | 老师碰一下学生手机，分享本周课程安排与作业清单 |
| 👥 会议 | 会议桌 NFC 标签碰一下，获取议程、资料链接与倒计时 |

> 每一次碰触，都是一次日程的无摩擦传递。

---

### 🔗 场景自动化联动

这是 Colendar 的扩展方向——**日程不仅记录时间，也可以在用户明确授权后准备数字环境**。

任务包启动时，自动触发预设的关联操作：

| 联动类型 | 示例 |
|---|---|
| 📲 打开 App | 健身包 → 自动启动 Keep 并跳转至对应课程 |
| 📄 打开文件 | 练琴包 → 自动打开乐谱 PDF |
| 🎵 播放音乐 | 大扫除包 → 自动播放预设的 Spotify / 本地歌单 |
| 🔕 系统状态 | 学习包 → 自动开启勿扰模式 + 全局禁用通知 |
| 💡 智能设备（规划中） | 电影包 → 调暗灯光、打开电视、静音手机 |

**未来扩展**：利用鸿蒙分布式能力，实现跨设备联动。一个"晨间启动包"可同步触发：手机关闭闹钟 → 手表显示今日天气 → 音箱播放早安播报 → 咖啡机开始工作。

## 🌟 愿景

Colendar 希望带给用户的最终体验是：**少做一次临场决定，多专注一次正在进行的步骤。**

每天醒来，你需要做的只是：
1. 看一眼今天的自动推荐日程
2. 像搭积木一样微调你的时间安排
3. 然后——跟着节奏走，剩下的交给系统

闹钟自动校准，应用自动打开，音乐自动播放，灯光自动调暗。你的日程像一台精密的时钟一样流畅运转，而你只需要专注于当下正在做的事情本身。

**时间是你创作的原材料，Colendar 是陪你把计划做完的工具。**
